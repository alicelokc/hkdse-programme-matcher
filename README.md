# HKDSE 課程配對 Webapp（MVP）

給學生輸入預計 HKDSE 成績，參考官方 JUPAS／E-APP 收生分數瀏覽可能適合的課程。

## 如何開啟

在專案目錄啟動本機靜態伺服器（需能讀 `data/programmes.json`）：

```bash
cd /workspace/jupas-eapp-2026/webapp
python3 -m http.server 8765 --bind 127.0.0.1
```

然後用瀏覽器打開：`http://127.0.0.1:8765/`

（亦可把整個 `webapp/` 資料夾部署到任何靜態網站託管。）

## 功能

1. 輸入核心科＋選修科預計等級（含 5*／5**）
2. 以未加權 Best 5（7 分制／8.5 分制）對照官方 Median／LQ（**只供參考，非取錄保證**）
3. 按院校、興趣、JUPAS 編號、系統篩選
4. 課程卡顯示分數年份、來源連結、簡介／出路（來自 JUPAS Short Description；未能核實中文者顯示官方英文摘要）

## 數據注意

- 理大等多數課程分數含科目加權，尺度與未加權 Best 5 不同 → 介面會標示「未能直接比較」
- 城大部分資料為 2025 成績按 2026 公式重算（非 2026 實際收生）
- 港大／浸大／JUPAS 中央 2026 實際分截至編譯日未見
